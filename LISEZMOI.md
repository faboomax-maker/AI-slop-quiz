# The AI Slop Game – web app

Le code, les textes et la liste des images sont dans index.html. Les images elles-mêmes sont dans le dossier images/ (compressées en JPEG, environ 80 Ko chacune). Les autres fichiers servent à l'icône sur l'écran d'accueil.

## Tester tout de suite sur ton PC
Double-clique sur index.html : le jeu s'ouvre dans ton navigateur. Tu peux jouer à la souris (glisser la carte) ou avec les flèches gauche/droite du clavier.

## Mettre le jeu en ligne gratuitement (GitHub Pages)
1. Crée un compte gratuit sur github.com.
2. Clique sur « New repository », nomme-le par exemple ia-ou-pas-ia, coche « Public », puis « Create repository ».
3. Clique sur « uploading an existing file » et glisse les 5 fichiers de ce dossier (index.html, manifest.webmanifest et les 3 icônes). Valide avec « Commit changes ».
4. Va dans Settings > Pages. Dans « Branch », choisis « main » puis « Save ».
5. Attends une ou deux minutes : ton lien apparaît en haut de la page, du style https://tonpseudo.github.io/ia-ou-pas-ia/

## L'installer sur iPhone
1. Ouvre le lien dans Safari.
2. Touche le bouton Partager (carré avec une flèche), puis « Sur l'écran d'accueil ».
3. L'icône apparaît sur l'écran d'accueil et le jeu s'ouvre en plein écran, comme une app.

Envoie simplement le lien à ton ami pour qu'il fasse pareil.

## Modifier le jeu
- Dosage des sources par partie : tableau MIX au début du script dans index.html.
- Retirer une image gênante : cherche son lien dans index.html et supprime son entrée.
Après une modification, renvoie index.html sur GitHub : tout le monde a la nouvelle version au prochain lancement.
